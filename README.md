# 🕌 Islamic Spiritual Tracker

**Track Your Prayers • Calculate Qaza • Spiritual Guidance**

---

## 📖 Introduction

**Islamic Spiritual Tracker** is a web application that helps Muslims track their prayers, calculate missed (Qaza) prayers, and receive Islamic guidance for spiritual growth.

---

## ✨ Features

### 📊 Section 1: Prayer & Life Tracker

* ✅ Daily prayer calculation
* ✅ Lifetime prayer analysis (from age 12)
* ✅ Time spent analysis (sleep, food, mobile, washroom)
* ✅ Life projection for **60 / 70 / 80** years
* ✅ Age calculation based on birth date

---

### ⏳ Section 2: Qaza Prayer Calculator

* ✅ Calculate missed prayers from age 12
* ✅ Prayer consistency percentage (**0–100%**)
* ✅ Years / Months input for prayer history
* ✅ Time required to complete Qaza prayers

---

### 📚 Section 3: Islamic Guidance

* ✅ Positive actions to adopt
* ✅ Negative habits to avoid
* ✅ Spiritual advice and reminders
* ✅ Contact with Islamic scholars

---

### 🎨 Additional Features

* ✅ Modern, futuristic UI design
* ✅ Fully responsive layout
* ✅ Urdu language interface
* ✅ Interactive cards and statistics
